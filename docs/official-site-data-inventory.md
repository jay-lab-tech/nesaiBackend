## Data yang tidak boleh diimpor

Halaman SPMB memuat nama, NISN, dan asal sekolah calon murid. Data pribadi tersebut **tidak boleh** dimasukkan ke database publik NESAS, pencarian, seed, atau konteks NESAI. Untuk halaman PPDB cukup gunakan informasi prosedur, jadwal, persyaratan, tautan pendaftaran, dan pengumuman yang memang disetujui untuk publikasi.

## Dampak ke database NESAS

Tabel awal sudah ada, tetapi tabel `schools` saat ini hanya menyimpan nama, deskripsi, visi, misi, dan tautan sosial. Sebelum import data sekolah, perlu migration tambahan untuk NPSN, alamat, telepon, email, akreditasi, tahun berdiri, luas area, serta statistik yang memiliki tanggal pembaruan.
